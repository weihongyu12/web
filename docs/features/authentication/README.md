## 核心认证方式

### [手机验证码登录](/docs/features/authentication/smscode)

- 推荐首选登录方式
- 自动注册新用户
- 支持防刷机制和流量控制

### [微信登录](/docs/features/authentication/wechat)

- 移动端优先的第三方登录
- 支持网页扫码和微信内授权
- 自动获取用户基本信息

### [邮箱密码登录](/docs/features/authentication/password)

- 传统账号密码方式
- 集成密码强度检测
- 支持浏览器凭据管理

### [用户注册](/docs/features/authentication/registration)

- 自动注册优先策略
- 支持多方式账户创建
- 渐进式用户引导流程

## 统一特性

✅ 全平台兼容性  
✅ 自动化测试支持  
✅ 审计日志记录  
✅ 多因素认证准备  

## 接入指南

1. 选择适合业务的认证方式
2. 配置对应服务参数
3. 集成前端组件
4. 测试认证流程
5. 监控登录指标

详细配置请参考各子模块文档。
